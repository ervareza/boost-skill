# Changelog

All notable changes to Boost Skill are documented here.

## [v1.1.2] - 2026-09-11
### Changed
- Complete rebranding across all files, runners, test suites, CLI installers, and adapters to **Shiro X Dev/boost**.
- Update script prefixes, verification logging, and error messaging to `[Shiro X Dev/boost]`.

## [v1.1.1] - 2026-09-11
### Changed
- Rebrand and update protocol identity to **Shiro X Dev/boost**.
- Update Hermes Agent adapter and CLI banner to display Shiro X Dev/boost.

- Harden the universal installer with dry-run, backups, atomic writes, and explicit adapter status.
- Add a canonical protocol manifest and machine-readable compatibility metadata.
- Add isolated test fixtures for worktree lifecycle, verification failure, and installer idempotence.
- Replace unsupported vendor-specific claims with documented native mechanisms or clearly labelled prompt adapters.

## [1.0.0] - 2026-09-03

- Initial public repository.
- Added the tool-agnostic `/boost` specification.
- Added Hermes, Claude Code, Codex CLI, OpenCode, Aider, Cursor, Windsurf, Roo Code/Cline, Devin, and GitHub Copilot adapter drafts.
- Added initial worktree and verification helpers.
